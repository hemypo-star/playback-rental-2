# Handoff: Playback Rental — Swiss/Bento redesign

## Что это

Справочная спека дизайна «Swiss + bento» для `hemypo/playback-rental`, **ветка `2.0`**,
приложение **`apps/cms`** (Next 16 App Router + React 19 + Payload 3 + Tailwind v4).

`main`/`prod` и корневой `src/` (легаси Vite + Supabase) — вне объёма.

## Важное про доставку

Пакет **не является** инструкцией по внедрению и **не содержит** файлов конфигурации.
Дизайн доставляется машинно, конвейером репозитория:

```bash
node tools/design-sync.mjs extract "Playback Rental - прокат техники.html"
node tools/design-sync.mjs spec
node tools/design-sync.mjs audit apps/cms/src
```

Бандл — не картинка, а полная машиночитаемая спецификация экранов; `spec` превращает
нестандартные `style-hover`/`style-focus` в настоящий CSS и в токены Tailwind v4.
Правки дизайна идут в бандл, не в `tokens.css` / `interactions.css` — те затрутся.

Прежние `tailwind.config.ts` и `index.css` из пакета **удалены**: это был Tailwind v3
под легаси-приложение. В `apps/cms` токены живут в `@theme` внутри
`apps/cms/src/styles/prototype.css` и уже соответствуют дизайну.
(До 2026-09-21 это был `global.css`; перестройка витрины на `src/prototype/*`
сделала живым `prototype.css`, а `global.css` перестал импортироваться и удалён.)

## С чего начать

`08-instruction.md` — весь рабочий наряд: контекст, порядок работ по блокам A–E,
приёмка, запреты. Остальные файлы читаются по ссылкам из него.

## Фидельность

**High-fidelity.** Значения финальные: точные hex, размеры в px, кривые Безье,
длительности в мс. Прототип — источник истины по внешнему виду, но это не
production-код: там инлайн-стили и фейковые данные.

Где прототип и репозиторий расходятся по данным (город, часы работы, цены, поля формы) —
источник истины репозиторий.

**Правило цены:** цена = ставка за сутки × число суток × количество. Скидок за
длительность нет. Срок меньше суток считается как одни полные сутки. Скидка в
**наборах** — это разница между суммой позиций и ценой набора, она остаётся.

## Активы

- Шрифт: **Golos Text**, self-hosted в `apps/cms/public/fonts` (4 woff2, variable 400–800),
  подключён через `@font-face` в `prototype.css` и `preload` в layout. Не Google Fonts.
- Иконки: в дизайне их почти нет — стрелки и знаки набраны текстом (`→`, `←`, `+`, `−`,
  `✓`, `✕`, `↺`, `◆`). Оставить текстом: это часть свисс-характера.
- Изображения: в прототипе плейсхолдеры; в приложении — Payload media через `mediaUrl()`.
- Логотип: в шапке текстовый (`PLAYBACK` 700 / `RENTAL` 400 / `®` акцентом), svg — в favicon/OG.
