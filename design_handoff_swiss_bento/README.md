# Handoff: Playback Rental — Swiss/Bento redesign

## Что это

Пакет для полного, с нуля, переноса дизайна «Swiss + bento» в существующий фронтенд
`hemypo/playback-rental` (Vite + React 18 + TS + Tailwind + shadcn/ui + Supabase).

Предыдущая попытка «совместить» дизайн с кодовой базой дала результат «похоже, но не то,
нет анимаций, другие размеры». Причина не в разметке, а в трёх слоях, которые остались
от старой темы и перебивают дизайн:

1. **Токены shadcn не тронуты.** `--radius: 0.8rem`, `--foreground: 222 47% 11%` (синеватый),
   `font-sans: Inter`. Любой `Dialog`, `Popover`, `Calendar`, `Button` рисуется старой темой,
   даже если вокруг него верстка новая.
2. **Шрифт фактически не подключён.** В `src/index.css` `@import url(...Inter...)` стоит
   **внутри `@layer base` после правил** — по спецификации CSS такой `@import` игнорируется.
   Приложение рисуется системным шрифтом, поэтому «другие размеры» и другой ритм строк.
3. **Глобальные «iOS-оптимизации»** (`img { content-visibility:auto; contain-intrinsic-size:200px 200px }`,
   `.grid { contain: layout style; transform: translateZ(0) }`, `.card { backface-visibility:hidden; perspective:1000px }`)
   создают композитные слои на каждой сетке и карточке. Они ломают `position: sticky`,
   размывают тени и текст и глушат hover-анимации. Именно это читается как «не свисс».

Поэтому порядок работ в `05-migration-plan.md` начинается не с экранов, а со сноса этих трёх слоёв.

## Фидельность

**High-fidelity.** Все значения в документах — финальные: точные hex, размеры в px,
кривые Безье, длительности в мс. Прототип — источник истины по внешнему виду и поведению,
но это **не production-код**: там инлайн-стили и фейковые данные. Задача — воспроизвести
эти экраны средствами репозитория (Tailwind + shadcn), сохранив значения из `01-tokens.md`
до пикселя.

Где прототип и репозиторий расходятся по данным (город, часы работы, цены, поля формы) —
источник истины репозиторий и `06-audit.md`, а не прототип. Список расхождений — в аудите, п. 4 и 21.

## Как этим пользоваться

1. Прочитать `01-tokens.md`, применить `tailwind.config.ts` и `index.css`.
2. Прочитать `03-motion.md` целиком до того, как писать первый компонент.
   Анимации здесь — не украшение, а язык интерфейса: hover-подъём карточки, spring на смене
   состояния, вход блока. Если их не заложить в примитивы сразу, вернётся «нет анимаций».
3. Идти по `05-migration-plan.md`. Не начинать с экранов.
4. Спорные места по логике аренды и корзины закрыть по `06-audit.md` до вёрстки —
   часть находок меняет состав экранов (согласия на обработку ПДн, e-mail, скидки за срок).

## Активы

- Шрифт: **Golos Text** (Google Fonts), веса 400/500/600/700. Лицензия OFL.
- Иконки: `lucide-react` уже в проекте. В дизайне иконок почти нет — стрелки и знаки
  набраны текстом (`→`, `←`, `+`, `−`, `✓`, `✕`, `↺`, `◆`). Оставить текстом:
  это часть свисс-характера. Иконки lucide — только там, где текст не читается (соцсети).
- Изображения: в прототипе — плейсхолдеры `<image-slot>`. Реальные фото приходят
  из Supabase storage через `ProductImage`.
- Логотип: `public/logo.svg` из репозитория. В шапке дизайна логотип текстовый
  (`PLAYBACK` 700 / `RENTAL` 400 / `®` акцентом) — оставлен как есть, svg используется в favicon/OG.
