# 05 — План внедрения

Для агента (Claude Code) в репозитории `hemypo/playback-rental`, ветка `main`.
Порядок обязателен: экраны — в самом конце. Каждый шаг — отдельный PR с критериями приёмки.

Правило на весь план: **сначала снести старый визуальный слой, потом строить.** Прошлая
попытка провалилась потому, что новая вёрстка ставилась поверх живых токенов shadcn,
неподключённого шрифта и глобальных composite-хаков.

## PR 1 — Фундамент: шрифт, токены, снос старого CSS

1. **Шрифт.** В `index.html` в `<head>`, до всех стилей:
```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Golos+Text:wght@400;500;600;700&display=swap" rel="stylesheet">
```
Удалить `@import` шрифта из `src/index.css` (он там внутри `@layer base` после правил и
поэтому игнорируется — корень «других размеров»).

2. **Заменить** `tailwind.config.ts` на файл из этого пакета.
3. **Заменить** `src/index.css` на файл из этого пакета. Он удаляет:
   `glass-panel`, `glass-card`, `btn-ghost`, `heading-1..4`, `chip`, `card-hover`,
   `animate-in*`, `img{content-visibility}`, `.grid{contain/translateZ}`,
   `.card{backface-visibility/perspective}`, глобальный `input{font-size:16px}`,
   `html{scroll-behavior:smooth}`.
4. `grep` по проекту на все удалённые классы. Ожидаемо сломается визуал в 20–40 местах —
   это нормально, починка в PR 3–8. Не добавлять классы обратно.
5. Удалить тёмную тему из UI, если где-то есть переключатель (в дизайне её нет).

**Приёмка:** страница рисуется Golos Text (проверить в DevTools → Computed → font-family);
фон `#EFEEEB`; фокус чёрный, не синий; `position: sticky` в каталоге работает;
консоль чистая. Визуальные регрессии в компонентах допустимы.

## PR 9 — Финальный проход

1. Мобайл 360 / 390 / 768: все хит-таргеты ≥44px, ни одного горизонтального скролла.
2. Контраст: весь текст ≥4.5:1 (`#75736E` на `#EFEEEB` = 4.6:1 — проходит только для
   ≥12.5px; на белом 4.9:1). Мельче 12px — только caps 600.
3. Клавиатура: полный проход по главной, каталогу, товару, корзине; модалка дат
   с `focus-trap` и `Esc`; фокус видим всюду.
4. Lighthouse: CLS < 0.05 (все медиа с `aspect-ratio`), никаких ручных `will-change`.
5. `grep` на остатки: `glass`, `heading-1`, `animate-in`, `Inter`, `shadow-soft`,
   `shadow-medium`, `translateZ`, `content-visibility` — должно быть пусто.

**Приёмка:** чек-лист выше пройден, чек-лист `06-audit.md` закрыт или задачи заведены.
