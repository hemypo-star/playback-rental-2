# 04 — Экраны

Формат: **сетка → блоки сверху вниз → файлы репозитория**. Токены не повторяются — см. `01-tokens.md`.

Обёртка любого экрана сайта:
```
.pb-shell > .pb-grid       (max-w 1460, padding 14px 30px 0, 12 колонок, gap 14)
main { animation: bn-fade 380ms ease both }
```

## S5. Как это работает / Контакты · `src/pages/HowItWorks.tsx`, `Contacts.tsx`

Как это работает: карточка-заголовок → 4 шага 3+3+3+3 (номер 42px/600 muted, заголовок 18px, текст 14px) → FAQ-аккордеон (строка 15px, `accordion-down 240ms expo`, «+»→«−» spring) → тёмный CTA-блок.

Сайдбар sticky `top: 14px`: карточка radius 24, аватар 46px + имя 15px/500 + роль caps, разделитель, пункты навигации radius 13 (`padding 11px 13px`, 13.5px, активный ink/белый, hover quiet, `transition background 260ms ease`), внизу «Выйти» muted.
