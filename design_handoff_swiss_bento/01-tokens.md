# 01 — Токены

> **Живой источник токенов — `@theme` в `apps/cms/src/styles/global.css`** (Tailwind v4),
> плюс сгенерированный `docs/design-reference/spec/tokens.css` для кривых и длительностей.
> Значения там уже соответствуют дизайну. Этот документ — справка: частоты использования,
> правила применения и то, чего в `@theme` нет (шкала типографики, спейсинг, сетка).
> Колонку HSL можно игнорировать: она была нужна легаси-теме shadcn на Tailwind v3.

Все значения извлечены из прототипа `Playback Rental.dc.html` (частота использования указана,
где это важно для приоритета). Ничего не округлять: `10.5px`, `13.5px`, `-0.045em` — намеренные.

| `pb-surface` | `#FFFFFF` | `0 0% 100%` | все карточки, шапка (86% альфа), модалка |

### Чернила и акцент

| Токен | HEX | Применение |
|---|---|---|
| `pb-ink` | `#0A0A0A` | текст, тёмные блоки, primary-кнопка, выбранный день |
| `pb-ink-2` | `#2A2925` | абзац описания товара (16.5px) |
| `pb-ink-3` | `#4A4844` | абзацы на светлом, подписи чекбоксов |
| `pb-muted` | `#75736E` | лейблы caps, мета, вторичные числа (83 использования — самый частый цвет) |
| `pb-accent` | `#D62410` | акцент: hover primary, «Изменить», ромбы в бегущей строке, ®, `::selection`, подчёркивание ссылок |

**Правило акцента:** `#D62410` никогда не используется как фон крупного блока и никогда — как
цвет длинного текста. Только: hover primary-кнопки, микро-метки ≤11px, 1–2 знака, тонкая линия,
бейдж «выгода», сумма нерабочего времени.

### Статусные тона (бейджи в админке и чипы наличия)

| Тон | Фон | Текст | Смысл |
|---|---|---|---|
| `ok` | `rgba(10,10,10,0.06)` | `#0A0A0A` | свободно / подтверждено / опубликовано |
| `ink` | `#0A0A0A` | `#FFFFFF` | в аренде / выдано / возврат |
| `warn` | `rgba(214,36,16,0.12)` | `#D62410` | новая заявка / ТО / мало / черновик |

Контраст: `warn` даёт 4.9:1 — проходит AA для 10px caps. Не заменять на прозрачность ниже 0.12.

## 2. Типографика

**Одна гарнитура: `Golos Text`.** Fallback: `Helvetica, Arial, sans-serif`.
Веса: 400 (только слово «Rental» в лого), **500 (все заголовки и числа)**,
**600 (все caps-лейблы и кнопки, 101 использование)**, 700 (лого, счётчик, цифра в комплекте).

Базовое: `font-size: 15px; line-height: 1.45; font-feature-settings: 'tnum' 1;`
`-webkit-font-smoothing: antialiased; text-rendering: optimizeLegibility;`

`tnum` обязателен: без него цены и календарь «пляшут» при смене цифр.

«технические» подписи и очень крупные заголовки, почти без промежуточных размеров.

## 3. Радиусы

| Значение | Применение | Частота |
|---|---|---|
| `999px` | все кнопки, чипы, счётчики, полосы прогресса | 39 |
| `26px` | hero-блоки, промо-слайд, модалка, тёмный CTA | 8 |
| `24px` | стандартная карточка/панель | 23 |
| `22px` | stat/KPI-карточка, карточка клиента, related | 6 |
| `20px` | шапка сайта |
| `18px` | строка позиции в корзине, строка промо-списка, итог-плашка |
| `16px` | изображение внутри карточки, вложенная плашка, плитка дат | 11 |
| `14px` | инпут, плашка комплекта, строка таблицы, hover-строка | 22 |
| `13px` | пункт навигации админки |
| `12px` | пункт фильтра, день в модалке, слот времени |
| `11px` | день в компактном календаре товара |
| `7px` | чекбокс, ячейка гантта |
| `4px` / `3px` | квадратик легенды |
| `50%` | круглые кнопки (46px, 38px, 34px, 32px, 28px, 24px), аватар (46px) |

Обратите внимание: **радиус уменьшается с глубиной вложенности** (24 карточка → 16 медиа →
14 плашка внутри → 7 чекбокс). Это правило, а не набор случайных значений.

## 4. Тени

Одна рабочая тень:

```
--pb-lift: 0 26px 48px -32px rgba(10,10,10,0.42);
```

Только на hover карточки. В покое карточка **без тени**, отделена только границей `0.07`.

Служебные:
- шапка: `0 2px 3px rgba(10,10,10,0.03)` — постоянно;
- модалка: `0 40px 90px -40px rgba(10,10,10,0.6)`;
- нижний переключатель экранов прототипа: `0 18px 40px -20px rgba(10,10,10,0.7)` (в проде не нужен).

Никаких других теней. Никаких `shadow-glass`, `shadow-soft`, `shadow-medium` из старого конфига.

## 5. Сетка и спейсинг

- Контейнер: `max-width: 1460px; margin: 0 auto;`
- Паддинг страницы: `14px 30px 0` (десктоп) → `12px` по бокам на ≤760px.
- Низ страницы: `padding-bottom: 96px`.
- **Основная сетка: 12 колонок, `gap: 14px`** (30 использований — единственный «настоящий» гэп).
- Sticky-элементы: `top: 96px` (сайд-панели), `top: 14px` (сайдбар админки).

Раскладки блоков (десктоп): hero 7/5 · stat 3+3+3+3 · промо 8/4 · категории 4+4+4 ·
наборы 4+4+4 · «популярное»/«как это работает» 7/5 · товар 7/5 · корзина 7/5 ·
админка `246px 1fr`.

### Брейкпоинты (ровно три)

| ≤1180px | скрываем часы работы в шапке |
| ≤1020px | 12 колонок → 6; все `span` → 6; сетки 3-в-ряд → 2; sticky → static; админка → 1 колонка |
| ≤760px | десктопный hero → мобильный кроп; все сетки → 1 колонка; промо-блок 620px высоты; паддинг 12px |

### Внутренние отступы

| Контекст | Паддинг |
|---|---|
| Hero-карточка | `38px 36px 34px` |
| Стандартная карточка | `24px` или `26px` |
| Карточка-заголовок страницы | `26px 28px` |
| Stat/KPI | `20px 22px` |
| Карточка с медиа (каталог, категория) | `14px` / `16px` (медиа вплотную к краям) |
| Строка таблицы | `15px 10px` (+ `margin: 0 -10px` для полноширинного hover) |
| Строка позиции корзины | `18px 14px` (+ `margin: 8px -14px 0`) |
| Плашка комплекта | `12px 14px` |
| Инпут | `height: 48px; padding: 0 16px` |
| Модалка | `22px 24px` заголовок, `18px 24px` секции |

### Высоты интерактивов

`54px`/`56px` — primary CTA · `48px` — инпут, кнопка в модалке · `46px` — круглая
навигация промо · `44px` — кнопка в карточке каталога · `42px` — «весь каталог», кнопка
админки · `38px` — чип шапки, круглая кнопка закрытия · `36px` — «добавить» у аксессуара ·
`28px`–`30px` — шаги степпера · `24px` — тумблер (42×24, кнопка 18px).

**Мобильный минимум 44px** соблюдён у CTA; чипы 38px в шапке на мобильном заменяются на
кнопки 44px (см. `06-audit.md`, п. 20).
