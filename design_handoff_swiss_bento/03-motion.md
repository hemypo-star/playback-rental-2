# 03 — Анимации

**Читать до того, как писать первый компонент.** «Нет анимаций» в прошлой попытке — не
пропущенный полиш, а потеря половины дизайна: в этой системе движение несёт смысл, а не
украшает. Здесь ровно три кривых, восемь кейфреймов и семь правил. Больше не добавлять.

## Кривые

| Название | Значение | Смысл | Где |
|---|---|---|---|
| `expo` | `cubic-bezier(0.16,1,0.3,1)` | «объект приезжает и мягко встаёт» | вход блоков, подъём карточки, рост gap, зум фото, раскрытие |
| `spring` | `cubic-bezier(0.34,1.56,0.64,1)` | «состояние переключилось» (лёгкий перелёт) | чекбокс, тумблер, день календаря, слот времени, ячейка гантта, поворот ✕ |
| `ease` | `ease`, 240ms | смена цвета/фона — не должна привлекать внимание | все hover по цвету |
| `promo` | `cubic-bezier(0.45,0,0.15,1)` | медленный кросс-фейд | только слайдер акций |

Правило: **цвет всегда `240ms ease`. Геометрия — `expo`. Состояние — `spring`.**
Если непонятно, какая кривая нужна, значит анимация не нужна.

## Длительности

| мс | Что |
|---|---|
| 220–240 | фон, цвет, hover-подложка строки |
| 260 | фон пункта навигации (чуть медленнее — крупная площадь) |
| 320 | spring-состояния |
| 380 | рост `gap` в кнопке, `bn-pop`, `bn-fade` |
| 420 | подъём карточки + тень |
| 560 | вход блока (`bn-in`, `bn-rise`) |
| 900 | раскрытие изображения (`bn-clip`), линейка (`bn-rule`), зум фото, кросс-фейд промо |
| 1200 | сдвиг фона промо-слайда (параллакс) |
| 2.6s | пульс индикатора «открыто» |
| 40s | бегущая строка |

## Кейфреймы

```css
/* Вход блока: снизу вверх с микро-масштабом. Основной. */
@keyframes bn-in   { from { opacity:0; translate:0 18px; scale:.99 } to { opacity:1; translate:none; scale:none } }
/* Вход текста внутри блока: без масштаба, короче путь. */
@keyframes bn-rise { from { opacity:0; translate:0 14px }            to { opacity:1; translate:none } }
@keyframes bn-fade { from { opacity:0 }                              to { opacity:1 } }
/* Пульс на смене значения: счётчик, итог, количество. */
@keyframes bn-pop  { 0% { scale:.6; opacity:0 } 60% { scale:1.12 } 100% { scale:1; opacity:1 } }
/* Линейка/полоса растёт слева. transform-origin: left обязателен. */
@keyframes bn-rule { from { transform:scaleX(0) }                    to { transform:scaleX(1) } }
/* Раскрытие изображения шторкой снизу вверх + уход масштаба. */
@keyframes bn-clip { from { clip-path:inset(0 0 100% 0); scale:1.06 } to { clip-path:inset(0 0 0 0); scale:none } }
@keyframes bn-mark { from { transform:translate3d(0,0,0) }           to { transform:translate3d(-50%,0,0) } }
@keyframes bn-blink{ 0%,100% { opacity:1 } 50% { opacity:.2 } }
```

### Критично: `translate`/`scale`, а не `transform`

`bn-in` и `bn-rise` анимируют **отдельные свойства** `translate` и `scale`, а не
композитный `transform`. Причина: карточка одновременно имеет `hover: translate 0 -4px`.
Если анимация входа заканчивается на `transform: none`, а hover ставит `transform`,
браузер конфликтует — карточка дёргается при наведении сразу после появления.
Именно этот баг был в первой версии дизайна и был исправлен переходом на `translate`/`scale`.

**Никогда не переписывать `bn-in` на `transform: translateY()`.** Так же и hover карточки
должен ставить `translate`, а не `transform`.

## Семь правил

### 1. Вход блока — один раз, со стаггером 60мс
Каждый блок сетки: `animation: bn-in 560ms expo both; animation-delay: index*60ms`.
Максимум 6 шагов задержки (360мс) — дальше без задержки, иначе низ страницы «доезжает» слишком долго.
Не привязывать к скроллу: `IntersectionObserver`-ревилы по всей странице — запрещены
(в дизайне их нет, и они выглядят как шаблон).

### 2. Карточка при hover поднимается на 4px и получает единственную тень
```
translate: 0 -4px; box-shadow: 0 26px 48px -32px rgba(10,10,10,0.42);
border-color: rgba(10,10,10,0.15);
transition: translate 420ms expo, box-shadow 420ms expo, border-color 240ms ease;
```
Ровно 4px и ровно эта тень — во всех карточках приложения. Разные значения на разных
экранах читаются как небрежность.

### 3. Кнопка при hover меняет фон и раздвигает gap
Никогда: `scale`, `opacity`, поднятие. Только `background` + `gap` (см. P1).

### 4. Смена состояния — spring 320ms
Чекбокс, тумблер, день, слот времени, ячейка гантта (`scaleY(1.16)`), крестик (`rotate 90deg`).
Одна кривая на все — так интерфейс ощущается как один механизм.

### 5. Смена значения — `bn-pop` через `key`
Счётчик корзины, количество в строке, «К оплате». `key={value}` заставляет React
перемонтировать элемент → анимация играет заново. Без библиотек.

### 6. Строка списка при hover получает подложку, иногда сдвигает контент
```
hover: background #F4F3F1;
опционально: padding-left 10px → 18px, transition padding-left 380ms expo
```
Сдвиг padding — только в списке «Берут чаще всего» и в плашках комплекта
(`translate: 3px 0`). Не применять ко всем строкам.

### 7. Слайдер акций не двигает блоки
Меняются только: непрозрачность фонового изображения (`900ms promo`), его смещение
(`1200ms promo`), и текст перезаезжает `bn-rise` со стаггером `0 / 60 / 120мс`
(кикер → заголовок → описание). Сам блок стоит. Полоса автопрокрутки в активной
строке списка: `bn-rule 9000ms linear` (`transform-origin: left`).

Автопрокрутка: 9с на слайд, останавливается при `:hover` на блоке и при
`prefers-reduced-motion`, и навсегда после первого ручного клика по стрелке.

## Переходы между экранами

`main` при смене роута: `animation: bn-fade 380ms ease both` (главная — `420ms`).
Никаких slide/scale-переходов страниц. В репозитории есть
`src/components/AnimatedTransition.tsx` — либо привести к `bn-fade`, либо удалить.

## Скелетоны

Пока данные грузятся — не спиннер на весь экран (сейчас так в `App.tsx` и `Admin.tsx`),
а карточки-скелетоны в той же сетке:
```
background: #FFFFFF; border 1px solid rgba(10,10,10,0.07); radius 24px;
внутри: блоки #F0EFEC c radius 16px/999px в местах медиа/текста;
пульс: animation bn-blink 2.6s ease-in-out infinite (opacity 1 → .2 слишком сильно
       для скелетона — использовать opacity 1 → .55, длительность 1.6s)
```
Скелетон обязан занимать столько же места, сколько реальная карточка (`aspect-ratio`),
иначе появится CLS.

## prefers-reduced-motion

Уже в `index.css`: длительности анимаций → 0.001ms, переходы → 100ms, итерации → 1.
Дополнительно в JS: не запускать автопрокрутку промо, если
`matchMedia('(prefers-reduced-motion: reduce)').matches`.

## Производительность

- Анимировать только `opacity`, `translate`, `scale`, `clip-path`, `box-shadow`.
  Никогда — `width`, `height`, `top/left`, `margin`.
- `will-change` не ставить руками. В старом `index.css` он выставлялся на hover
  у `.card-hover` — убрать: браузер сам справляется, а лишние слои жрут память на мобильных.
- Бегущая строка (`bn-mark`) — дублированный контент + `translate3d(-50%)`. Один слой,
  бесконечно, без пересчёта раскладки. На `prefers-reduced-motion` — остановить.
